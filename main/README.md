## Постановка бизнес-задачи (неделя 1)
Сформулируй проблему как для реального стейкхолдера: "Компания теряет X% клиентов в год, стоимость привлечения нового в 5 раз выше удержания. Нужно найти, кого удерживать и как". Определи бизнес-метрики успеха (сэкономленный бюджет, ROI кампании), а не только accuracy/AUC.
